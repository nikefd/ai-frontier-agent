# 学习区入口与观察工作区

2026-11-16 首期。`/learn` 是独立学习区，`/learn/observe` 是CS2680第一阶段的本地记录工作区。与资讯站共用域名和现有账号壳，独立课程导航；不新增域名或暴露服务器编码执行权限。

## 现在能做什么

- 学习首页说明五阶段及当前完成范围；只有已实现阶段提供内部入口，后续阶段链接原课程材料。
- 观察页支持Claude Code JSONL/JSON数组，本地文件或粘贴，5MiB/10000记录上限。保留物理行号或数组序号、无效行诊断、重复/缺失调用ID提示。
- 上一条/下一条/位置滑块/自动回放/暂停/查看完整记录；进度代表原记录顺序，不代表真实耗时。进入目录选项暂停回放。长输出及原文分块显示最多16000字符，快照关联原文最多展示最近10条。
- 工具请求与结果按运行段、父范围、调用ID关联；重复ID不在歧义范围内猜配。助手消息快照不重复计调用。result的is_error优先于subtype=success。父调用存在且唯一时形成树，缺失提示、循环关系安全降级；深度超过7层用原始记录核对。
- 本次新采集并人工脱敏的启动失败示例可一键载入：Claude Code未登录，没有工具执行、没有修复。公开文件仅白名单字段；不是成功案例。

首期没有网站内实时CLI执行入口或完整原课程作业验收。2026-11-16已用余下两次授权验证Claude Code + DeepSeek Flash的真实代码修复和同会话续问，并上线审查后回放。本轮3次授权全部使用：一次此前启动失败、一次修复、一次续问。实际子任务未产生，不能标为已验收。用户配置更新后，采集器从明确的~/.claude/settings.json读取必要provider字段，仅内存注入隔离CLI环境，API模式不要求Anthropic账号登录。

## 模块与生命周期

`learn/learn-app.js`负责页面壳、路线内容及生命周期；`observe.js`负责导入/游标/回放控制；`trace-model.js`只做无IO的解析、投影、树关系；`trace-view.js`转义呈现，最终回复复用既有安全Markdown；`learn.css`隔离学习区样式。没有引入另一个Agent引擎或API。

nav的applyRoute对学习路由立即呈现，不等待auth；navigationAuthReady不重建学习工作区。普通站内/学习区链接走HistoryAPI，语言切换仍整页加载。离开学习区与身份变化会停止回放、撤销异步读文件/示例响应、清除DOM及内存，不上传、不保存、不把私有输入放入URL。

资讯入口在首页/侧栏/移动更多菜单。学习区进入后隐藏资讯侧栏、资讯页标题与移动底栏；使用自己的“路线/观察/返回资讯”导航。保留原有`/learning`个人学习路径，和新`/learn`不同。
