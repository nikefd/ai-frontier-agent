# 开源发布准备

> 状态日期：2026-11-02。许可证已由项目所有者明确选择 Apache-2.0；实际仓库可见性与发布结果记录在最终发布验收中。

## 已完成

- 原创代码和文档采用 Apache-2.0；LICENSE 来自 Apache 官方原文，补充 NOTICE、THIRD_PARTY_NOTICES.md 与 Python 包许可元数据。
- 服务器交互 CLI 创建首个管理员，公开注册仅创建普通用户；没有管理员时返回 503。已有管理员时拒绝覆盖；普通用户即使匹配旧数据指定邮箱也不能继承旧资料。
- README 改为用途、Docker 快速开始、本地开发、配置费用和使用边界；补充首版 CHANGELOG。维护范围聚焦稳定来源、内容质量和自托管体验。
- 当前示例配置与种子数据不含生产账号、用户资料或抓取文章。运行数据、环境变量变体、扫描报告和本地构建产物排除在 Git/Docker 上下文之外。
- Gitleaks 8.30.1 经官方 SHA256 校验：初始全部可达引用的 148 个提交、额外不可达提交历史和不可达 blob 均为 0 命中；发布前继续扫描最终历史与导出树。报告使用 100% 遮盖，不上传到公开构建产物。
- 新增只读权限的 Secret scan CI，不依赖仓库密钥；AI PR Review 仅运行于同仓库分支，fork PR 不接收模型密钥。
- CONTRIBUTING.md 与 SECURITY.md 已补齐；第三方源内容不随软件许可重新授权。

## 发布验收

完成全部后再公开仓库并发布版本：

1. 全量 pytest、前端构建/依赖审计与 Python wheel 构建。
2. 从干净 Git 导出内容构建 Docker 镜像，在独立卷验证首次启动、未初始化注册拒绝、CLI 初始化、登录、普通用户注册以及重复初始化拒绝。
3. 对最终 Git 历史与导出树执行 Gitleaks，检查 GitHub CI。密钥扫描不是绝对保证，不承诺全网来源完整召回或上游永久可用。
4. 核对首版 tag/release 指向已验证提交，启用公开漏洞私密报告入口。

## 发布边界

公开的是代码仓库与版本材料。生产数据卷、账号/会话、SMTP、模型密钥和 X 登录凭证保持私有。Git 历史仍保留原作者身份与部分已删除的旧示例域名/邮箱；未做历史重写，也没有匿名化发布承诺。
